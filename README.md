#Amazon Clone

This is a simple Amazon Clone built using HTML and CSS. It is a static website that mimics the design and layout of Amazon's homepage.

Features

1.Responsive design

2.Navigation bar similar to Amazon

3.Product grid layout

4.Fotter design

5.Hover effects for buttons and images

Technologies Used

HTML

CSS

How to Run

Clone this repository:

git clone https://github.com/KiranHK-code/Amazon-clone.git

Navigate to the project folder:

cd amazon-clone

Open index.html in your browser

Future Improvements
